# Stage criteria (template; generate per client from their pipeline)

For each stage in the client's pipeline, record:

## <Stage name>
- **Entry evidence**: what must have happened to be in this stage (e.g. "discovery call held, need stated")
- **Exit evidence**: what must be true to move on (e.g. "decision-maker engaged, scope shared")
- **Typical contradicting evidence**: what suggests the deal is not really here
- **Clarifying question** when evidence is ambiguous

Keep criteria observable (a meeting happened, a document was sent), not subjective ("client seems keen").
